简化汽车自动驾驶纵向控制模型

这个项目是一个用 Simulink 搭建的自适应巡航控制（ACC）小模型。车辆根据与前车的距离、两车速度差和自身速度，给出纵向加速度指令，目标是稳定跟随前车并保持合适的车距。

模型文件为 `AutonomousDrivingACC.slx`。它主要用于理解自动驾驶纵向控制的闭环思路，没有加入横向控制、感知、路径规划、障碍物识别或真实车辆动力学。

模型中的信号关系如下：

前车恒定速度经过积分得到前车位置。本车加速度经过积分得到速度，再积分得到位置。前后车位置相减得到实际车距；实际车距与期望车距的差值经过比例控制，同时叠加两车相对速度反馈，并减去与本车速度有关的阻尼项，最终形成加速度指令。

使用的控制关系为：

加速度指令 = KpGap ×（实际车距 − 期望车距）+ KdRelativeSpeed ×（前车速度 − 本车速度）− DragCoeff × 本车速度

模型默认将前车速度设为 20 m/s，期望车距设为 25 m，前车初始位置为 60 m，本车从静止状态出发，仿真时间为 60 秒。`KpGap`、`KdRelativeSpeed`、`DragCoeff` 等参数保存在模型工作区，可按需要在 Simulink 的模型资源管理器中调整。

使用 MATLAB R2023a 或更高版本打开模型，并确认已安装 Simulink 后，直接点击“运行”即可。仿真结束后，可打开 `GapAndSpeedScope` 查看实际车距和本车速度的变化。

该模型适合作为学习或原型验证的起点。若用于更贴近实际的场景，还需要考虑执行器饱和、制动约束、传感器噪声、目标车状态估计、碰撞安全逻辑、横向控制和系统级验证。
